# 🏅 Olympics Analysis Dashboard

## Overview
An interactive data analysis dashboard built using Python and Streamlit to explore Olympic Games data.

## Features
- Medal Tally
- Overall Analysis
- Country-wise Analysis
- Athlete-wise Analysis
- Olympic Medal Prediction

## Tech Stack
- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Matplotlib
- Seaborn

## Dataset
Historical Olympic Dataset
